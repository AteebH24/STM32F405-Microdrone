# Flight Controller Schematic

This directory contains the electrical schematic and design documentation for the custom STM32F405 based microdrone flight controller.
## Main Subsystems
- STM32F405 microcontroller
- BMI270 six-axis IMU
- 1S LIPO battery power management
- TPS61023 boost converter
- Four MOSFET based brushed motor drivers
- FlySky receiver interface
- SWD programming and debugging interface
## Design Files

The complete schematic PDF is provided in this directory for reference.
