# PCB Layout

This directory contains the PCB layout and routing documentation for the custom STM32F405 microdrone flight controller.

## Board Specifications
- Two-layer PCB
- 1 oz copper
- STM32F405 based flight controller
- Four brushed motor driver channels
- Integrated power management and IMU circuitry
## Design Considerations
- Component placement and signal routing
- Power distribution and grounding
- PWM motor control routing
- SPI and UART communication interfaces
- connector placement and mechanical integration
## Design Files

PCB layout images and manufacturing files are provided for hardware review.
