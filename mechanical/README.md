# Microdrone Mechanical Design
## Project Overview

The microdrone frame was designed in SolidWorks and manufactured using FDM 3D printing.

The frame provides mounting locations for four brushed DC motors, the custom STM32F405 flight controller, the FlySky receiver, and the 1S LiPo battery.

## Design Considerations
- Compact four motor quadcopter configuration
- PCB mounting and component clearance
- Battery and receiver mounting
- Weight reduction and structural support
- Integration with the custom flight controller PCB
## Manufacturing
- CAD software: SolidWorks
- Manufacturing method: FDM 3D printing
- Material: PETG
- Printer: Bambu Lab A1
